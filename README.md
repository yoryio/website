# yoryio.github.io

Source for [yoryio.github.io](https://yoryio.github.io) — a threat intelligence
blog focused on adversary infrastructure, initial access, and N-day analysis,
with an emphasis on Latin America.

Built with [Jekyll](https://jekyllrb.com/) and the
[Minima](https://github.com/jekyll/minima) theme, published via GitHub Pages.

## Running locally

```
bundle exec jekyll serve
```
